Sketches and files for Processing (https://processing.org/), the fantastic interface for serial communications with my gadgets!

portLogger is a lightweight barebones program I wrote myself. It does the job!

For fun, I dumped PortLogger.pde into Claude.AI and said "Can you make an interface similar to the Arduino IDE where you can scroll up and see the past entries in the log? And can you make dropdown menus for baud rates, and a tick box for the timestamp? How nuts can we go here?" The result, after a few tweaks and refinements, was ClaudeLogger.pde. It was humbling to have this program generated in minutes. The question is no longer "Is AI useful?" The question has flipped. Am I useful in comparison? Well, maybe, for now.
